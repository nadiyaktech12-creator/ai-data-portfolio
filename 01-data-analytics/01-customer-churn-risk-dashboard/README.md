# Customer Churn Risk Dashboard

### Telco Customer Churn Analysis using Streamlit

---

## Business Problem

Customer churn is a major problem for telecom companies. Losing customers directly impacts revenue. This dashboard helps business teams quickly identify high-risk customer segments based on contract type, internet service, tenure, and monthly charges.

---

## Solution

An interactive Streamlit dashboard that allows users to:

- Filter customers by Contract Type and Internet Service
- View key metrics: Total Customers, Churned Customers, Churn Rate, and Average Tenure
- Analyze churn patterns through interactive charts
- Explore the filtered data

---

## Tech Stack

- Python
- Pandas
- Plotly
- Streamlit

---

## Features

- Interactive filters (Contract Type & Internet Service)
- KPI cards (Total Customers, Churn Rate, Avg Tenure, etc.)
- Churn distribution by Contract Type
- Churn distribution by Internet Service
- Monthly Charges distribution
- Tenure vs Monthly Charges scatter plot
- Expandable data table

# Credit Risk Scorecard

An interactive Streamlit app that estimates the probability of loan default from applicant details, classifies the result as **Low**, **Medium**, or **High** risk, and shows which features the model relies on most.

> **Disclaimer:** This project is for educational purposes only. It is not a real credit decision engine and must not be used for actual lending decisions.

**Live demo:** [Add Streamlit link here](https://credit-risk-scorecard1.streamlit.app/)

---

## Overview

The app trains a Random Forest classifier on the German Credit dataset and serves it through a simple web interface. A user enters applicant details, clicks **Predict**, and sees the probability of default, a progress bar, and a risk level. An expandable section shows a feature importance chart for the model.

| Risk level | Probability of default |
|------------|------------------------|
| Low        | below 33%              |
| Medium     | 33% to 60%             |
| High       | 60% and above          |

## Features

- Input form generated automatically from the dataset columns (number inputs and dropdowns)
- Probability of default with a metric and progress bar
- Low / Medium / High risk label
- Feature importance chart (top 10 features, one-hot columns grouped back into their original feature)
- Cached data and model loading for fast reruns

## Tech Stack

- Python
- Pandas
- Scikit-learn (RandomForestClassifier)
- Joblib (model and feature list persistence)
- Streamlit (UI and deployment)

## Dataset

- **German Credit** (OpenML `credit-g`, originally from the UCI Machine Learning Repository)
- 1,000 applicants, 20 features, binary target (`good` / `bad` credit)
- Downloaded automatically on the first run of `train_model.py` and saved as `german_credit.csv`

## How It Works

1. **Load data** from `german_credit.csv` using a path relative to the script (`Path(__file__).parent`), so it works from any directory and on Streamlit Cloud.
2. **Preprocess**: fill missing numeric values with the median, one-hot encode categorical columns with `get_dummies`.
3. **Split** the data 80/20 with stratification.
4. **Train** a Random Forest (200 trees, balanced class weights).
5. **Evaluate** with a classification report printed in the terminal.
6. **Save** the model and the exact list of feature columns with joblib.
7. **Predict** in the app: build a one-row DataFrame from the inputs, one-hot encode it, **reindex to the saved feature columns** (this prevents column order mismatch errors), then call `predict_proba`.
8. **Explain**: a feature importance chart shows which applicant attributes the model relies on most. It reflects what the model uses, not what causes default.

## Run Locally

```bash
# 1. Clone the repository and open this folder
cd 06_credit-risk-scorecard

# 2. Create and activate a virtual environment (Windows PowerShell)
python -m venv venv
.\venv\Scripts\Activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Train the model
python train_model.py

# 5. Launch the app
streamlit run app.py
```

## Model Performance

| Metric | Value |
|--------|-------|
| Accuracy | 0.76 |
| Precision (bad credit) | 0.60 |
| Recall (bad credit) | 0.60 |

Evaluated on a 20% hold-out set of 200 applicants (140 good, 60 bad).

## Limitations

- Small dataset (1,000 rows), so results are illustrative rather than production-grade.
- The risk bands are simple probability cut-offs, not calibrated lending policy.
- Feature importance shows model reliance, not causation.
- No fairness or bias audit has been performed, which is essential for any real credit model.


## Deployment

Deployed on Streamlit Cloud. Make sure `app.py`, `german_credit.csv`, `model.joblib`, `feature_columns.joblib`, and `requirements.txt` are all committed in the same folder.
